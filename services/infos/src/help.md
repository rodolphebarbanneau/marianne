Les titres de vos sources d’information des dernières 24 heures, regroupés en sujets : un sujet, ce sont les titres de sources différentes qui disent la même chose. Ils sont rangés par nombre de sources qui en parlent ; personne ne les choisit. SUITE et RETOUR passent d’un sujet à l’autre, ENVOI ouvre le sujet : comment chaque source le titre, ce que chacune est seule à dire, qui l’a dit quand.

Le fil donne les mêmes titres à leur heure ; le kiosque, source par source.

Marianne lit les journaux pour INFOS et ne montre que le titre, l’heure, le lien et le début de l’article : l’article s’ouvre chez la source. Vos sources se choisissent dans Réglages › Identité ; « toutes » montre aussi celles que vous avez écartées, pour cette fois.
