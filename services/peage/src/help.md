Les autoroutes en **flux libre**, sans barrière : chaque passage se paie après coup, en général dans les 72 heures, sur le site officiel de l’autoroute.

- Notez vos passages : le service compte le temps qu’il reste, et vos échéances rejoignent vos rappels.
- Payez sur le site officiel, ou avec Marianne : elle retrouve ce qui est dû avec votre plaque, et paie avec votre carte enregistrée (Réglages › Paiement) après votre oui, puis note le trajet payé.
- Aucun lien de paiement officiel n’arrive par SMS : un SMS de péage avec un lien est une arnaque.
- Dans Démarches › Mobilité, une tâche planifiée peut chercher vos passages non payés, tous les 2 jours par défaut, si vous ouvrez Marianne. Elle ne paie jamais ; quand elle trouve, « payer maintenant » lance le paiement avec vous.
