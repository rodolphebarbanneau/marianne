# The user guide

What Marianne is and how to use it, for the people who use it: installing it, getting started, the features, their data, help. It is written to be published as a website's content as well as read here.

- [`fr/`](fr/index.md): in French, the language of the app.
- [`en/`](en/index.md): in English.

Every language has the same files, with the same English names: `fr/install.md` and `en/install.md` are the same page. A change to one page goes to every language in the same pull request. Each folder starts at `index.md`, which lists the pages in their order.

The labels of the app are quoted as they appear on screen, in French (« créer mon archive »), followed in other languages by their meaning.

The technical documentation, for developers, is one level up, in [`docs/`](..): [design](../design.md), [services](../services.md), [content](../content.md).
