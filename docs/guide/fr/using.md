# Utiliser Marianne

## Les dossiers

Un dossier, c’est une conversation avec Marianne sur un sujet : une démarche, une question, un courrier à comprendre. Écrivez sur la page d’accueil pour en commencer un (ctrl+entrée en ouvre un nouveau de n’importe où). « + pièce » joint un document, et le menu à côté du bouton « envoyer » choisit le moteur du dossier.

Les dossiers en cours sont dans la colonne de gauche, avec « chercher » en haut pour en retrouver un. Ceux que vous mettez en veille reviennent à la date choisie, et ceux que vous classez restent à portée, dans « Classés ».

## Votre accord

Tout ce qui change votre profil, remplit un formulaire, signe, paie ou envoie passe d’abord par vous : Marianne vous le montre sur une carte, et attend votre accord.

## Le navigateur intégré

Marianne ouvre les sites dont elle a besoin dans le navigateur du dossier, à droite (le bouton « navigateur »). Elle vous demande votre accord avant d’aller en ligne, et toujours avant de signer, payer ou envoyer. Vous pouvez « prendre la main » à tout moment. Ce navigateur oublie tout quand l’archive se verrouille.

## Les pages

- **Actualités** : les nouvelles de plusieurs journaux, les rendez-vous du jour, quelques chiffres de la France.
- **Démarches** : les domaines de votre vie administrative (impôts, santé, logement, famille…), chacun avec son tableau de bord et ses démarches guidées, étape par étape.
- **Services** : les codes 3615, METEO, PEAGE, CARTE, PARLEMENT, ANNUAIRE. Tapez un code ou des mots dans la barre 3615 pour en trouver un. L’étoile épingle un service en tuile, en haut de « mes services », avec ce qu’il a de neuf pour vous : la météo du jour, un péage à payer. « + découvrir » propose les services officiels que vous n’avez pas encore ajoutés, puis ceux de la communauté. Avant d’ajouter un service, Marianne vous montre ce qu’il pourra faire. Un service qui a besoin d’une partie de votre profil, comme votre plaque d’immatriculation pour le péage, vous le demande d’abord.

## Votre profil

Dans Réglages › Moi, vous pouvez renseigner votre identité, votre foyer et vos pièces. C’est facultatif : cela aide Marianne à préparer vos démarches. Voir [Vos données](privacy.md) pour ce que le moteur en voit.

Dans Réglages › Identité, vous pouvez aussi indiquer, si vous le souhaitez, les groupes politiques dont vous vous sentez proche, et les thèmes qui comptent pour vous. Votre sensibilité sert seulement à comparer : 3615 PARLEMENT vous dit si vos élus votent comme vos idées, sans rien trier ni cacher. Vos thèmes font remonter les actualités et les scrutins qui en parlent. Vous choisissez quels services peuvent les lire, et voyez quand ils l’ont fait.

## Les touches

Comme sur un Minitel, la barre du bas montre les touches de l’écran :

| Touche     | Ce qu’elle fait                   | Raccourci   |
| ---------- | --------------------------------- | ----------- |
| ENVOI      | envoyer                           | entrée      |
| ANNULATION | arrêter Marianne, fermer          | échap       |
| CORRECTION | modifier mon dernier message      | ↑           |
| RÉPÉTITION | refaire la réponse                | ctrl+R      |
| SUITE      | page suivante                     | pg↓         |
| RETOUR     | page précédente                   | pg↑         |
| SOMMAIRE   | le menu de l’application          | ctrl+espace |
| GUIDE      | l’aide, les liens, vos raccourcis | F1          |

Et aussi : ctrl+K pour les commandes, ctrl+alt+espace pour chercher partout, ctrl+, pour les réglages, ctrl+maj+R pour recharger la fenêtre. Dans un service, F2, F3… ouvrent ses onglets, et F1 son guide. Sur macOS, cmd remplace ctrl, sauf pour le menu et la recherche. Tous se changent dans Réglages › Raccourcis clavier.
